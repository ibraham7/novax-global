# NovaX Global — موقع تصدير الأثاث التركي

موقع فاخر ثنائي اللغة (عربي / English) لشركة تصدير الأثاث التركي إلى الخليج والشرق الأوسط وأوروبا.

## التشغيل
افتح `index.html` مباشرة بالمتصفح، ما في حاجة لأي تثبيت.

## الملفات
- `index.html`: الصفحة
- `assets/css/style.css`: التصميم (الألوان في أول الملف تحت `:root`)
- `assets/js/main.js`: الحركات، والترجمة الإنجليزية، ورقم واتساب (`WHATSAPP`)
- `assets/img/logo.svg`: شعار مؤقت
- `docs/تحليل-المنافسين.md`: دراسة المنافسين
- `novax-global/`: مواد الشركة (الكتالوجات، اللوجو، متطلبات المدير)
